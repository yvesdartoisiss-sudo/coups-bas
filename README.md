# Coups Bas !

Jeux de bluff pour les soirées entre amis et en famille (dès 10 ans), chacun sur son téléphone,
ou seul contre des robots.

**Jouer :** https://yvesdartoisiss-sudo.github.io/coups-bas/

- **🗯️ Qui a dit ça ?** : tout le monde répond à la même question, réponses anonymes, chacun devine qui a écrit
  quoi. +2 par bonne devinette, +1 par joueur piégé par ta réponse : écris comme quelqu'un d'autre !
  Une manche sur trois : « Qui de nous est le plus susceptible de… ». 3 à 8 joueurs, 8 manches.
- **🐺 Loup-garou** : loups, Voyante, Sorcière, Chasseur, Cupidon, Salvateur, villageois, élection du Maire.
  Fiche de rôle au départ, guide à chaque étape, historique des votes, carnet de suspects.
  5 à 8 joueurs (robots compris), 15-20 min.

Entre amis : un joueur crée le salon (son téléphone sert de serveur, il garde la page ouverte), les autres
scannent le QR code ou tapent le code à 4 lettres. En solo : pas de chrono, les robots bluffent, comptent
les cartes, accusent et votent.

Anciennes versions : `express.html`, `classique.html` (Le Bluff reste dans le code mais n'est plus proposé).
