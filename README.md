# Coups Bas ! — le mystère du gâteau de Mamie

Jeu de soirée pour 2 à 8 joueurs, chacun sur son téléphone : enquête façon Cluedo, pièces à acheter
façon Monopoly, intrus façon Undercover, duels façon Bataille et coups bas façon Uno.

**Jouer :** https://yvesdartoisiss-sudo.github.io/coups-bas/

Un joueur crée le salon (son téléphone sert de serveur, il garde la page ouverte), les autres entrent
le code à 4 lettres ou scannent le QR code. Mode facile dès 10 ans, mode normal pour les adultes.
